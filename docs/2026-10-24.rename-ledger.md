# Rename ledger: freshtime to dozentimes (2026-10-24)

This project was called freshtime until 2026-10-24, when Jeremy renamed it to dozentimes.
This file records every change the rename made, inside and outside the repo, so a future agent can explain, repeat or undo it.
If you find "freshtime" in an old session log, a pi session folder, a cezar run record or a shell history, it means this project.

- The films in `video/` were not re-rendered, and issue #15 holds that work.

## Ledger rewrite

The ledger keys each fact by its absolute `source_path` and takes `project` from the folder name.
Moving the folder without this rewrite would have left the old rows live forever and ingested the same lines again under the new path.
Each ledger got one transaction:

```sql
BEGIN;
UPDATE facts SET source_path = replace(source_path, '/Users/jjrdar/create/freshtime/', '/Users/jjrdar/create/dozentimes/')
  WHERE source_path LIKE '/Users/jjrdar/create/freshtime/%';
UPDATE facts SET source_path = 'conversation:dozentimes' WHERE source_path = 'conversation:freshtime';
UPDATE facts SET project = 'dozentimes' WHERE project = 'freshtime';
UPDATE sources SET path = replace(path, '/Users/jjrdar/create/freshtime/', '/Users/jjrdar/create/dozentimes/')
  WHERE path LIKE '/Users/jjrdar/create/freshtime/%';
INSERT INTO facts_fts(facts_fts) VALUES('rebuild');
COMMIT;
```

| Ledger                                | Facts rewritten | Sources rewritten | Integrity check |
| ------------------------------------- | --------------- | ----------------- | --------------- |
| `ledger.db`                           | 86 of 1766      | 2 of 69           | ok              |
| `branches/feat-pi-time-poc/ledger.db` | 96 of 1776      | 2                 | ok              |

No `conversation:freshtime` rows existed, so that statement changed nothing.
Fact text, check rows and trace rows were not rewritten, because they record what was said and done at the time.
A copy of the main ledger from just before the rewrite is at `~/.dozentimes/ledger.pre-rename-2026-10-24.db`.

## Repeating the rename on another machine

A machine that pulls main after `5244e6e` has the new code but the old folders, so pi-time would start an empty ledger.
Run these, with nothing holding the ledger open:

```sh
mv ~/.freshtime ~/.dozentimes
mv ~/create/freshtime ~/create/dozentimes
git -C ~/create/dozentimes remote set-url origin https://github.com/jroethel/dozentimes.git
git -C ~/create/dozentimes worktree repair ~/.dozentimes/worktrees/*
install -m 755 ~/create/dozentimes/pi-time/pi-time-branch ~/.local/bin/pi-time
```

Then run the SQL above on each ledger under `~/.dozentimes`, with that machine's home path in place of `/Users/jjrdar`.
